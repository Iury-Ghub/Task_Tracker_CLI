## About the Project

"Basically, I built this project in Java using Jackson for data persistence. 
It was based on the https://roadmap.sh/projects/task-tracker from Roadmap.sh. 
This project helped me understand how persistence logic works."

## Features

- Add, Update, and Delete tasks

- Mark a task as in progress or done

- List all tasks

- List all tasks that are done

- List all tasks that are not done

- List all tasks that are in progress

## Technologies Used

- **[Language]** - Java
- **[Library]** - Jackson
